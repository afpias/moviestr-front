# План реализации

## Этап 0. Основа проекта

- Зафиксировать спецификации.
- Подключить `@afpia/eslint` и `@afpia/prettier`.
- Использовать ESLint 9 и Yarn.
- Настроить FSD-алиасы.
- Добавить PrimeVue, Aura, PrimeIcons и MSW.
- Добиться успешных lint, type-check, unit tests и build.

## Этап 1. Игровое ядро

- Создать модели игры и конечные состояния.
- Реализовать нормализацию ответа.
- Реализовать подсчёт очков.
- Добавить mock-подборку и несколько фильмов с шестью кадрами.
- Описать handlers `collections`, `games`, `suggestions`, `guesses`.
- Создать game store и persistence текущего раунда.
- Покрыть бизнес-логику unit-тестами.

## Этап 2. Пользовательский интерфейс

- Создать страницы главной, игры, правил, статистики и 404.
- Подключить PrimeVue AutoComplete, Button, Dialog, Skeleton и Message по необходимости.
- Реализовать светлую и тёмную темы.
- Проверить мобильный интерфейс от 360 px.
- Добавить component tests основного сценария.

## Этап 3. Каталог и контент

- Определить юридически допустимый источник кадров.
- Определить источник и правила обновления подборки `Top 250`.
- Убрать названия фильмов из URL и имён кадров.
- Подготовить процесс проверки порядка сложности кадров.
- Добавить резервные изображения и обработку ошибки загрузки.

## Этап 4. Production backend

- Перенести выбор фильма и правильный ответ на backend.
- Добавить серверное состояние раунда и rate limiting.
- Подписывать или ограничивать URL кадров при необходимости.
- Добавить production API без изменения feature-интерфейсов.
- Проверить, что mock-код не включается в production.

## Этап 5. Будущие возможности

- авторизация;
- профиль;
- история игр и расширенная статистика;
- рейтинг игроков;
- ежедневный фильм;
- дополнительные подборки;
- административная панель;
- социальный шаринг.

Каждая возможность проходит отдельное уточнение требований и не должна заранее усложнять MVP.

## Открытые вопросы перед контентным этапом

- Какой источник определяет `Top 250`?
- Где и на каких условиях хранятся кадры?
- Нужно ли исключать фильмы определённых возрастных рейтингов?
- Нужны ли локализованные названия кроме русского и оригинального?
- Как формируется случайная выборка и предотвращается частое повторение фильмов?

## Технический долг инструментов

- Обновить `@afpia/eslint` для ESLint 10 и актуальной ветки TypeScript.
- После выпуска совместимой версии убрать временное ограничение проекта на ESLint 9.
- Проверить peer-зависимости пакета и исключить React/Next-плагины из установки для Vue-проектов, если соответствующие опции выключены.
