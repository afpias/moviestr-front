# Спецификации Moviestr

`docs` содержит только функциональные SDD-пакеты. Общие правила проекта, архитектуры, кода, тестов и Git находятся в
корневом [`AGENTS.md`](../AGENTS.md).

## Процесс

1. `spec.md` — что и зачем делаем: границы, требования и критерии приёмки.
2. `plan.md` — как реализуем: архитектура, данные, API, этапы и риски.
3. `tasks.md` — конкретные проверяемые задачи реализации.
4. Implement — выполнение задач в коде.
5. Verify — проверка результата по требованиям и критериям приёмки.
