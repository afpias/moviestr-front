# Moviestr specifications

Moviestr — Vue-игра, в которой пользователь угадывает фильм по шести последовательно открывающимся кадрам.

Эта папка — основной источник требований к проекту. Документы описывают текущий MVP, а не все возможные будущие функции.

## Стек

- Vue 3, TypeScript, Pinia и Vue Router.
- PrimeVue 5 и Aura.
- MSW для mock API.
- Vitest и Vue Test Utils.
- ESLint и Prettier из пакетов Afpia.

## Основные команды

```sh
yarn dev
yarn commit
yarn validate
yarn build
```

## Приоритет требований

При противоречии использовать следующий порядок:

1. Явное актуальное решение владельца проекта.
2. Документы в `docs/`.
3. Автоматические правила ESLint, Prettier и TypeScript.
4. Существующий код.

Если новый запрос меняет описанное решение, сначала обновляется соответствующая спецификация, затем код и тесты.

## Definition of Ready

Задача готова к разработке, если определены:

- пользовательский результат;
- состояния загрузки, успеха, пустого результата и ошибки;
- затрагиваемые API-контракты;
- место кода в FSD-структуре;
- проверяемые критерии приёмки.

## Definition of Done

Изменение завершено, если:

- поведение соответствует спецификации;
- внешние данные типизированы и проверены на границе API;
- добавлены тесты на новую бизнес-логику и значимое поведение компонента;
- нет новых ошибок TypeScript, ESLint и Prettier;
- успешно выполняются `yarn validate` и `yarn build`;
- документация обновлена, если изменился контракт или архитектурное решение.
