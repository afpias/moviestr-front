# Проверка изменений

Прочитать [AGENTS.md](../../../AGENTS.md). Определить область текущей задачи по запросу, `git status --short`,
`git diff` и `git diff --cached`; отличать свои изменения от исходного состояния пользователя.

## Выбор проверок

- Документация и инструкции: проверить ссылки, согласованность правил и отсутствие незаполненных шаблонов;
  выполнить `yarn format:check` и `yarn lint`.
- Код и tooling: выполнить `yarn validate`; для значимой реализации также `yarn build`.
- Бизнес-логика: добавить или обновить тесты критических переходов, ошибок и внешних данных.
- UI: проверить затронутое взаимодействие, клавиатуру, фокус, загрузку и ошибки; для изменений layout проверить
  ширину 360 px и desktop, отсутствие горизонтального скролла. Не считать сборку визуальной проверкой.
- Функциональность с SDD: сверить затронутые requirement ID и сценарии приёмки, обновить трассировку в спецификации.

Не добавлять тесты ради повторения реализации или проверки текста документации. Для локального CSS-исправления
обычно достаточно визуальной проверки и обязательных команд. Уже успешные проверки повторять только после изменений,
влияющих на их результат, или при появлении новых оснований для проверки.

## Ошибки и результат

Исправлять ошибки, вызванные своей реализацией, в пределах текущего запроса. При отдельном запросе только на проверку
сообщить найденные проблемы без автоматических правок. Не запускать массовый `--fix` по чужим изменениям.
Отделить существующие ошибки от новых по diff и адресным проверкам; не ослаблять правила ради успешного запуска.

Если полный прогон заблокирован посторонними ошибками или окружением, выполнить доступные адресные проверки и явно
указать, что они не заменяют полный прогон. Не объявлять все проверки успешными и не отмечать зависимые задачи готовыми.

Передать результат: что проверено, какие команды прошли, что упало или не запускалось и почему. Для проверенной части
реализации далее применяется [commit-changes](../commit-changes/SKILL.md). Самостоятельная проверка не разрешает коммит.
